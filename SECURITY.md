# Security Policy

This repository is a **personal fork** ([parasite6/superset](https://github.com/parasite6/superset)) of [superset-sh/superset](https://github.com/superset-sh/superset). It is not a supported product and is not a security response channel for other people.

## Do not report vulnerabilities here

Please **do not** open public issues, discussions, or private advisories on this fork expecting a fix, bounty, or coordinated disclosure from me. I am not patching exploits or bugs for third parties on this tree.

## Upstream (where to report)

If you found a vulnerability in Superset itself, report it to the upstream project:

1. **GitHub private vulnerability reporting (preferred):** ["Report a vulnerability"](https://github.com/superset-sh/superset/security/advisories/new) on `superset-sh/superset`
2. **Email:** [support@superset.sh](mailto:support@superset.sh) with "Security" in the subject line

Follow their [SECURITY.md](https://github.com/superset-sh/superset/blob/main/SECURITY.md) for scope, expectations, and supported versions.

## This fork

- No SLA, no acknowledgment window, no credit process.
- No promise that this fork tracks upstream security releases.
- If you only care about a maintained build, use [upstream releases](https://github.com/superset-sh/superset/releases).
